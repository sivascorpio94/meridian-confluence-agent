# Portfolio Screenshot Checklist

Capture screenshots at a consistent browser width and remove account menus,
tokens, email addresses, terminal history, and unrelated browser tabs.

Recommended images:

1. `01-agent-answer.png` — direct answer with the canonical citation.
2. `02-conflict-warning.png` — under-review and superseded warnings.
3. `03-agent-activity.png` — MCP tool calls and timing information.
4. `04-source-ranking.png` — semantic score, metadata adjustment, and final
   score for the three live pages.
5. `05-confluence-labels.png` — fictional page labels only; hide account data.
6. `06-refresh-command.png` — 14 unchanged embeddings skipped.
7. `07-architecture.png` — rendered architecture diagram.
8. `08-test-suite.png` — complete passing test summary.

Do not publish `.env`, AWS account numbers, Atlassian tokens, personal email
addresses, AWS login output, Docker credential files, or real employer content.
