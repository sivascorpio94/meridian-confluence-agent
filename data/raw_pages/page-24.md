# Deprecated: Old Intranet Access Portal

> ⚠️ **DEPRECATED** — This page documents a system that was decommissioned in August 2023. Do not use this information for new access requests.

## Summary

The Old Intranet Access Portal was Meridian's legacy self-service access management system. It provided a web interface for requesting system access and viewing approval status.

**Decommissioned:** August 15, 2023  
**Replacement:** ServiceNow Access Catalog (all functionality moved)

## What changed

| Feature | Old Portal | ServiceNow Catalog |
|---|---|---|
| Access request submission | Custom web form | ServiceNow catalog items |
| Approval workflow | Email-based | Automated routing to managers/approvers |
| Status tracking | Portal dashboard | ServiceNow ticket tracking |
| Historical audit trail | Limited (6 months) | Full retention (3+ years) |

## Migration path

If you were using the Old Intranet Portal:

1. Go to **ServiceNow Access Catalog** (https://meridian.service-now.com/catalog)
2. Search for the system you need access to (Mosaic UI, Orion, Vault, etc.)
3. Submit your request through ServiceNow instead
4. All future requests must use ServiceNow; the old portal no longer accepts submissions

## Data retention

Access records from the Old Portal were migrated to ServiceNow for compliance and audit purposes. Historical approvals and access logs are available upon request to the Security/IAM team.

## Support

The Old Intranet Portal is no longer supported. For questions about historical data or migration assistance, contact **iam-support@meridian.example**.
